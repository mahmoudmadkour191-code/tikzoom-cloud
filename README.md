# TikZoom Cloud 🚀

منصة استضافة بوتات تليجرام تعمل **24/7 مجانًا** على GitHub Actions.

## المميزات

- 🤖 **208+ قالب بوت جاهز** في 36 مجال (بوتات حقيقية كبيرة من GitHub، مُفحوصة أمنيًا)
- 🛡️ **فحص أمني بطبقتين**: قواعد ثابتة + Gemini AI — الرفض فقط للكود الذي يهاجم السيرفر
- ⭐ **نظام VIP**: رفع الملفات حصري للأدمن، والمستخدمون يفعّلون VIP من الأدمن
- 💾 **حالة مشفرة** داخل المستودع (Fernet) — البوتات والبيانات تعيش عبر إعادة التشغيل
- 🔄 **تشغيل مستمر**: كل دورة ~5.4 ساعة ثم handover تلقائي + watchdog كل 15 دقيقة

## كيف يعمل

1. `run.yml` يشغّل المنصة (polling) لمدة ~5.4 ساعة
2. قبل انتهاء الدورة: حفظ الحالة مشفرة → استدعاء الدورة التالية
3. `watchdog.yml` يفحص كل 15 دقيقة ويحيّي المنصة لو وقعت
4. بوتات المستخدمين تعمل كـ subprocess معزولة (venv لكل بوت + حماية sandbox)

## أوامر الأدمن

| الأمر | الوظيفة |
|-------|---------|
| `/addvip <id> [أيام]` | تفعيل VIP لمستخدم |
| `/delvip <id>` | إزالة VIP |
| `/viplist` | قائمة المشتركين |
| `/setadmincontact @user` | رابط التواصل في بوابة VIP |
| `/broadcast <نص>` | إذاعة للجميع |
| `/admin` | لوحة التحكم |

## الأسرار المطلوبة (Repo Secrets)

`PLATFORM_BOT_TOKEN` · `ADMIN_IDS` · `FERNET_KEY` · `STATE_KEY` · `GEMINI_API_KEY` · `HF_TOKEN` · `ADMIN_CONTACT` (اختياري)
